The name of my language is Viper. 

Number literals:
[0-9]+(\.[0-9]+)?
Examples:
5
123
12.5
0.25
String literals:
"[^"]*"
Examples:
"hello"
"hello world"
""
Identifiers:
[A-Za-z_][A-Za-z0-9_]*
Examples:
test
test123
_name

Viper uses mostly the same rules as Lox. It supports identifiers, numbers, strings, keywords, operators, punctuation, comments, and an EOF token.
Comments start with // and continue until the end of the line.
Whitespace is ignored. Newlines are used to keep track of line numbers for errors.
Numbers are stored as floating point values, so a number like 5 is printed as 5.0.

The scanner is written in Python and uses the built-in sys module.
To run a source file:
python main.py filename.lox
To run interactive mode:
python main.py
Then type Viper code directly into the terminal.
Tests can be reproduced with:
python main.py all_tokens.lox
python main.py edge_cases.lox
python main.py bad_character.lox
python main.py bad_string.lox

Known Limitations:
Viper currently only has the scanner portion of the interpreter.
It only supports // comments and does not support block comments.
Numbers like .5 are not treated as one decimal number. They are scanned as a DOT followed by NUMBER 5.
Strings do not currently support escape characters.
